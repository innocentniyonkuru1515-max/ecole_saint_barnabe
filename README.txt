ÉCOLE SAINT BARNABÉ — SITE WEB

1. Ouvrir le site
- Décompressez le dossier ZIP.
- Ouvrez le dossier ecole_saint_barnabe.
- Double-cliquez sur index.html.
- Le site fonctionne dans Chrome, Firefox ou Edge.

2. Fichiers
- index.html : page d'accueil
- ecole.html : présentation de l'école
- formations.html : fondamental et post-fondamental
- internat.html : vie et caractéristiques de l'internat
- admission.html : informations et formulaire de pré-demande
- contact.html : adresse et formulaire de contact
- style.css : apparence du site
- script.js : menu mobile et formulaires
- assets/ : logo et illustration locale

3. Personnalisation importante
Les informations qui n'ont pas été fournies (téléphone, e-mail, frais, dates, équipements réels, horaires officiels, classes exactes) ne sont pas inventées. Ajoutez les renseignements confirmés par l'administration avant de publier le site.

4. Limite des formulaires
Les formulaires vérifient les champs et préparent un message copié dans le presse-papiers. Ils ne transmettent pas les données à l'école et ne sauvegardent pas les demandes sur un serveur. Pour recevoir réellement les demandes, il faudra connecter un serveur ou un service de formulaire.

5. Images hors ligne
Le logo et l'illustration sont dans le dossier assets. Ils ne nécessitent pas de connexion Internet.
